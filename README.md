# مُسَمِّع (Musamme') - رفيق حفظ وتسميع القرآن الكريم 📖

تطبيق ويب تقدمي (PWA) ذكي وخفيف جداً، مصمم لتسميع القرآن الكريم ومقارنة قراءة الحافظ لحظياً مع النص القرآني بالرسم العثماني، والتنبيه التلقائي بالصوت والاهتزاز عند حدوث أي خطأ أو نسيان.

---

## ✨ المميزات الرئيسية
1. **تسميع ذكي مباشر (Real-Time Recitation Tracker):**
   * يستمع لتلاوة القارئ كلمة بكلمة.
   * يقارن النطق بقاعدة بيانات المصحف الشريف بدقة متناهية.
2. **تنبيه فوري عند الخطأ أو النسيان:**
   * **صوت تنبيه هادئ (Soft Chime):** عبر تقنية Web Audio API دون الحاجة لملفات صوتية ثقيلة.
   * **اهتزاز الهاتف (Haptic Feedback):** اهتزاز ناعم ينبه الحافظ فوراً.
   * **تظليل بصري أحمر:** للكلمة المنسية أو الخاطئة لكشف موضع الزلل.
3. **أقل استخدام للبيانات (Data-Saver / Offline-Ready):**
   * تطبيق PWA كامل يعمل بدون اتصال بالإنترنت بعد أول فتحة.
   * تخزين محلي كامل لنصوص سور وآيات المصحف الـ 114 بالرسم العثماني.
4. **دقة 99% عبر وضع النطاق المحدد (Targeted Context):**
   * يختار الحافظ السورة ونطاق الآيات (مثلاً: من الآية 1 إلى 20)، مما يحصر مجال البحث ويلغي الأخطاء العشوائية.
5. **وضع الحافظ المحترف ووضع المراجعة:**
   * **وضع الحافظ:** إخفاء الكلمات حتى ينطقها الحافظ من ذاكرته.
   * **وضع المراجعة:** نص خافت للتتبع والمراجعة السريعة.
6. **يعمل على كافة الأجهزة:**
   * هواتف آيفون (iOS عبر إضافة إلى الشاشة الرئيسية).
   * هواتف أندرويد (تثبيت PWA أو تحويله إلى APK).
   * الحواسيب والأجهزة اللوحية.
7. **تقرير وملخص الإتقان:**
   * حساب نسبة الإتقان المئوية، وحصر الكلمات التي تحتاج مراجعة وتثبيت.

---

## 🚀 المعمارية التقنية (Tech Stack)
* **Frontend:** Vanilla Modern ES6 Modules, HTML5, CSS3 (Mobile-First responsive design).
* **Audio Engine:** Web Audio API (توليد أصوات التنبيه اللحظية).
* **Vibration Engine:** Web Vibration API.
* **Speech-to-Text:** Web Speech API مع تطبيع ذكي للنص القرآني (Arabic Normalization & Fuzzy Levenshtein Matcher).
* **Typography:** خط المدينة المنورة الرسمي بالرسم العثماني (`uthmanic-hafs.woff2`).
* **PWA:** Service Worker (Offline caching) + Web App Manifest.
* **Hosting:** مهيأ للنشر الفوري على Vercel بنقرة واحدة عبر `vercel.json`.
